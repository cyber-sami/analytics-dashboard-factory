# About bayer_pack.xlsx

`bayer_pack.xlsx` is the synthetic data pack provided to participants of the Since AI Hackathon 2026 (Bayer challenge, "Build Less, Build Better: AI for Governed Analytics"). All values in it are synthetic and illustrative; it contains no patient-level, personal or real Bayer internal data. It was not created by this project and is not covered by the MIT licence in the repository root. It is included only so the engine can run.
